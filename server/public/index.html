Sync

Keep several sm servers in sync through a private git repository (sm-vault). The repository holds only ciphertext with hashed names; the key is in a key file locked with your password.

Create a private repository (e.g. sm-vault, empty for the first server). Add this server's key under Settings › Deploy keys with write access. Each server has its own key, so you can revoke one machine.

Choose the sm-vault.key from the first server and type the password it was made with. Secrets from the vault are added here; secrets only this server has are uploaded.

Rotate

Replaces the value with a new random one, generated on the server. Agents get the new value from their next sm command.

Anything that still uses the old value (a database user, an external service, a deployed app) must be updated to the new one, or it stops working. The new value is shown right after rotating, with a Copy button.
